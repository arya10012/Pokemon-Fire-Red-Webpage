# 🚀 GETTING STARTED

### ① Clone the repository

```bash
git clone https://github.com/arya10012/pokemon-fire-red.git
```

### ② Enter the project

```bash
cd pokemon-fire-red
```

### ③ Install dependencies

```bash
npm install
```

### ④ Launch the experience

```bash
npm run dev
```

🎮 Open the local URL shown in your terminal and begin your journey through **Kanto**.

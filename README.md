# 🔥 Pokémon FireRed — Interactive Web Experience

A modern, interactive **Pokémon FireRed fan website** inspired by the classic Kanto adventure.

The project combines the nostalgic visual style of Pokémon FireRed with a modern web interface, interactive Pokémon data, animations, and responsive design.

## ✨ Features

* 🔥 FireRed-inspired modern UI
* 📖 Kanto adventure & story timeline
* 📕 Interactive Kanto Pokédex
* 🔍 Pokémon search and filtering
* 🧬 Pokémon details and stats
* 🌿 Interactive starter Pokémon selection
* 🏆 Kanto Gym Badge showcase
* 🚀 Team Rocket section
* 🎲 Random Pokémon generator
* 📊 Trainer progress widgets
* 🌗 Day/Night visual mode
* ✨ Smooth animations and micro-interactions
* 📱 Fully responsive design
* 🎮 Hidden Pokémon-themed Easter egg

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* PokéAPI

## 🎮 Experience

Explore the Kanto region, discover Pokémon, view their stats, revisit the FireRed storyline, and interact with different Pokémon-themed elements throughout the site.

The design combines:

**Retro Pokémon aesthetics × Modern UI × Interactive Web Experience**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/arya10012/pokemon-fire-red.git
cd pokemon-fire-red
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
